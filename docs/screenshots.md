2. Экран регистрации.

4. Создание публикации с предпросмотром изображения.
5. Профиль пользователя.
6. Поиск пользователей.
7. Уведомления.
8. Админ-панель со статистикой и жалобами.

10. MinIO Console с загруженными объектами: `http://localhost:9001`.
11. Результаты k6 smoke/planned теста.
12. Docker Compose logs с поднятыми сервисами.
